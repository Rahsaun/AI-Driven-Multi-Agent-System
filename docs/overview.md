# Project Overview

## Purpose

**AI-Driven Multi-Agent System** is a personal research project examining how artificial intelligence behaves when interacting with a live operating system inside a virtual machine. The research focuses on decision-making, tool use, autonomy, reliability, and security.

The project was inspired by a reported incident involving an AI assistant operating on a Mac mini and unexpectedly modifying files. This prompted an interest in studying AI operating-system access in a controlled environment.

## Research questions

- What does an AI agent do when given broad operating-system access?
- What security vulnerabilities or failure modes can emerge from autonomous tool use?
- How does an AI navigate files, execute commands, and make decisions?
- What unexpected actions, incorrect assumptions, or hallucinations occur?
- How can multiple specialized agents collaborate on complex tasks?

## Scope

The experiments documented so far involve Claude, an Ubuntu virtual machine, terminal-based scripts, and email automation. Multi-agent collaboration is a **future project goal**, not a capability demonstrated in the current log.
