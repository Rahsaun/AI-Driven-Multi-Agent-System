# Project Roadmap

This roadmap converts the original README's next steps into trackable goals. Unchecked items are planned work, not completed features.

## Agent capabilities

- [ ] Implement clearly separated agent roles and responsibilities.
- [ ] Test agents collaborating on a complex task.
- [ ] Document which actions are autonomous and which need approval.

## Safety and observability

- [ ] Add structured logs for tool calls and results.
- [ ] Expand controlled security experiments.
- [ ] Document least-privilege permissions and network controls.
- [ ] Track anomalies with reproducible evidence.

## Research and reporting

- [ ] Compare behavior across multiple AI models.
- [ ] Publish a findings summary with supporting experiments.
- [ ] Add reproducible setup instructions.
- [ ] Add test cases and evaluation criteria.

## Documentation maintenance

For every new experiment, add a dated entry to [experiments.md](experiments.md). Record notable risks and errors in [security.md](security.md), and update this roadmap when milestones change.
